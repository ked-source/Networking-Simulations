# Networking-Simulations

# 🧠 Network Labs – GNS3 & Cisco Packet Tracer

Welcome to my virtual networking lab repository! This contains a collection of hands-on labs and network topologies created using **Cisco Packet Tracer** and **GNS3**.

🔧 Built for practice, study, and exploration of real-world networking scenarios.

---

## 📁 Project Structure

```
network-labs/
├── packet-tracer/       # Cisco Packet Tracer (.pkt) projects
│   ├── vlan-lab.pkt
│   ├── ospf-routing.pkt
│   └── ...
├── gns3/                # GNS3 topology and config files
│   ├── bgp-simulation/
│   │   ├── project.gns3
│   │   ├── configs/
│   │   └── ...
│   └── ...
└── README.md
```

---

## 🧪 Tools Used

- 🖥️ [Cisco Packet Tracer](https://www.netacad.com/courses/packet-tracer)  
- 🌐 [GNS3](https://www.gns3.com/)  
- 📄 Various router and switch configuration files

## 📚 Topics Covered

> These are some of the topics explored in the labs:

- 🔹 IP Subnetting  
- 🔹 VLANs & Trunking  
- 🔹 Static & Dynamic Routing (RIP, EIGRP, OSPF, BGP)  
- 🔹 NAT, DHCP, ACLs  
- 🔹 WAN technologies  
- 🔹 Network troubleshooting and simulation
